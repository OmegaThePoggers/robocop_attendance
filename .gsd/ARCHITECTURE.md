## Overview

The Robocop Attendance System is a full-stack web application designed for automated face recognition-based attendance tracking. It consists of a React frontend and a FastAPI (Python) backend using SQLModel for the database. Video streams are processed to detect and recognize faces against a set of known embeddings.

## Data Flow

1. Student/Admin logs into the React frontend.
2. Frontend sends requests via `api.js` to the FastAPI backend.
3. Backend authenticates using JWT tokens.
4. For attendance: Video frames are sent/processed, faces are detected by `face_recognition`, and compared against embeddings.
5. Attendance records are updated in the SQLite database via SQLModel.
